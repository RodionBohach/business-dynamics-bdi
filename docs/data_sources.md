# Data sources

Source: Eurostat.
Download date: 2026-10-08.
Format: gzip-compressed TSV.

Eight local extracts were downloaded from seven Eurostat datasets. Local filenames include descriptive labels; `total` and `Y1_Y2_Y3` distinguish two extracts from the `bd_size` dataset.

The downloaded files are retained unchanged in `data/raw` and are excluded from version control. Later downloads may differ because of Eurostat revisions.

## Source snapshot manifest

`raw_sources_manifest.json` records the filename, download date,
SHA-256 checksum, raw row count, year columns, and unique dimension
values for each of the eight local extracts.

The manifest is generated by:

python notebooks/document_raw_sources.py

Dimension values describe the contents of the saved extracts.
They do not imply that every possible combination has an observation
or a non-missing value.
